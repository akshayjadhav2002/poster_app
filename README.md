# posterapp

A new Flutter project.
link of apk https://drive.google.com/file/d/1MgLITRsoBA6xCUU0DymRb5cVS9isFI2p/view?usp=sharing
The app allows admins to create and manage posters by uploading images or adding text-based content. Users can view, share, and download these posters. Firebase services (Authentication, Firestore, and Storage) handle data storage, while Flutter provides the cross-platform framework. Admins have additional privileges, such as editing and deleting posts. The app fosters seamless interaction between users and engaging visual content.
